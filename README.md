HubBot - гибридная система для управления задачами, которая объединяет скорость работы через мессенджер и удобство полноценного веб-интерфейса. проект создан для быстрой постановки задач и удобного контроля за их выполнением сотрудниками.


Telegram-бот для менеджера:
    
    Создание новых задач командой /add прямо в чате.
    Установка точных дедлайнов (на принятие задачи в работу и на её выполнение).
    Мгновенное получение файлов с результатами работы от сотрудников.
    Автоматические уведомления об истекших сроках.

Веб-дашборд для сотрудников:
    
    Авторизация (вход в систему).
    Главная страница с автоматически рекомендуемыми свободными задачами.
    Канбан-доска со списком всех тикетов и их актуальными статусами («Не выполнено», «В процессе», «Выполнено», «Просрочено»).
    Возможность "Забрать тикет" в работу в один клик.
    Загрузка файлов (отчетов, результатов) при завершении задачи.

Технологии

    Бэкенд: Python 3.14+
    Веб-фреймворк: Flask
    Telegram API: pyTelegramBotAPI (Telebot)
    База данных: SQLite3 (встроенная, надежная, без лишних зависимостей)
    Фронтенд: HTML5, Vanilla CSS
    Инфраструктура: Docker

Как запустить проект 

  Откройте терминал в папке с проектом.
  Соберите Docker-образ одной командой:
  
    docker build -t hubbot .
  Запустите контейнер :
  
    docker run -p 5000:5000 -v task-data:/app/data hubbot
